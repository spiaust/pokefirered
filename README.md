# Pokémon European Tour — playable prototype

Current update: **v0.59** expands historical London with Westminster,
Parliament Square, Whitehall, the Thames and two crossings. Walk east from
reception. Quests and save progress remain available. See
[directions and historical limits](data/geography/HISTORICAL-LONDON.md)
and [playing instructions](EUROPE.md). The first historical landmark passes
are complete; fuller streets and finer architectural details remain next.

This workspace contains the first England/France/Germany prototype.
Its first tour quest rewards visiting the guides in the three starting cities.
Local trail trainers and station shops provide battles and repeatable supplies.
Version 0.9 connects the six rail stops with intermediate stations, itinerary
previews, and booked destinations that can be saved and resumed after exploring.
Version 0.40 adds a Le Havre dockworker task: read the entrance notice,
confirm the instructions with the captain, and record a fifteenth milestone.

Version 0.41 unlocks free, repeatable care with the Le Havre dockworker
after the captain confirms the dock instructions.

Version 0.42 adds an optional port report to Ada in Oxford and a sixteenth
historical journal record after the Le Havre dock task.

Version 0.43 unlocks a Celebi destination choice after the port report:
return to the Chantilly refuge or directly to Le Havre.

Version 0.44 adds onward travel from Le Havre to Southampton reception,
with a welcome, both return routes and the seventeenth journal milestone.

Version 0.45 adds a Southampton luggage search and return, with saved
progress and an eighteenth historical journal milestone.

Version 0.46 unlocks free, repeatable Southampton party care after the
luggage task, including existing completed saves.

Version 0.47 adds Southampton to Celebi's return destinations after the
luggage task, alongside the refuge and Le Havre.

Version 0.48 closes the Southampton reception chapter with an optional
report to Ada and the nineteenth historical journal milestone.

Version 0.49 opens historical London reception from Southampton, with
Rose's welcome, both return routes and the twentieth journal milestone.

See [EUROPE.md](EUROPE.md) for playing and building it, and
[TESTING.md](TESTING.md) for the verification record.
The release sequence and planned next stages are in [ROADMAP.md](ROADMAP.md).

Version 0.20 opens the Celebi storyline: after earning the Thunderbadge,
meet Ada in Oxford, investigate a sighting in Chantilly Forest, and return
with your report. Version 0.21 adds a playable trip to a fictional Chantilly
refuge in 1940,
a short task helping a child and Eevee, and a return through Celebi at any time.
Version 0.22 continues with a station-post visit and confirmed departure news
for the refuge. Version 0.23 adds a historical train to Beauvais reception,
where Elise and Eevee find a place together. Version 0.24 closes the first
historical arc with a return message and an account recorded by Ada. Version
0.25 adds a supply run that opens free, repeatable party care at Beauvais.
Version 0.26 opens a Beauvais garden, where Luc needs help finding his Pidgey.
Version 0.27 adds a Town Map story journal with current leads and milestones.
Version 0.28 extends it with regional story, Gym reward and city-stamp guidance.
Version 0.29 opens an onward historical trip to Amiens and Nora's arrival briefing.
Version 0.30 adds Nora's reunion task for Mira and Meowth, with journal guidance
and progress saved across return visits. Version 0.31 unlocks free party care
with Nora after that reunion. Version 0.32 lets you record the Amiens account
with Ada in Oxford and adds a tenth journal milestone. Version 0.33 follows
with a checked travel bulletin for Nora in Amiens. Version 0.34 opens the
onward train to Rouen, an arrival welcome and two return routes.
Version 0.35 gives Rouen a separate riverside layout with paved banks and a
crossing, including migration for older Rouen saves. Version 0.36 adds Leon's
missing route-book task on the far bank. Version 0.37 makes its completion
unlock free, repeatable party care with Leon. Version 0.38 expands the
historical journal to thirteen milestones across two readable records pages.
Version 0.39 adds a historical transport connection from Rouen to Le Havre,
a port welcome and return routes. The tree-edge fixes are included.
